# Как показывать диаграммы

Блок ```mermaid в чате Claude Desktop / claude.ai не рендерится, а mermaid.js внутри виджета даёт нечитаемый Гант в тёмной теме (белые полосы, светлый текст на белом). Поэтому:

| Что | Чат с виджетом (`show_widget`) | Итоговый `.md` |
|---|---|---|
| Гант | шаблон `references/gantt-widget.html` | mermaid `gantt` |
| Архитектура | SVG по правилам виджета (`c-*` классы) | mermaid `flowchart` |

Перед первым `show_widget` за сессию вызови `read_me` визуализации (module `diagram`).

## Гант — `gantt-widget.html`
Проверено: виджет чата (тёмная тема) и отдельная страница (светлая/тёмная, ширина телефона 375px без горизонтального скролла). Цвета текста берутся из темы чата, а без неё — из собственных fallback-значений шаблона.
- Скопируй файл целиком в `widget_code`, меняй **только блок ДАННЫЕ** и строку `sr-only`. Даты, раскладка, сетка недель, легенда, сводка сравнения считаются сами.
- **Сценарии команды — в одном виджете**: массив `scenarios` = Минимум, (Оптимум), Максимум. Сверху автоматически строится сводка «до прода» по всем сценариям, ниже — Гант каждого. Шкала дат общая, поэтому длины сравнимы на глаз.
- Шаблон сам проверяет, что у одного человека (секции) задачи не пересекаются, и выводит ⚠ под диаграммой. **Если появилось ⚠ — исправь данные и перерисуй, не показывай так.**
- Общие задачи (например, релиз) можно вынести в константу и переиспользовать в сценариях — шаблон копирует задачи для каждого сценария.
- Цвета — сплошные средние тона (проверено в тёмной теме). Не заменяй их на `var(--bg-*)` — в тёмной теме сливаются с фоном.
- Секции: `prep` / `dev` / `qa` / `rel`. Одна секция = один человек/поток, чтобы была видна загрузка.
- Логика плана: ревью сторов — задача 1–3 дня **перед** раскаткой, а не веха параллельно с ней. Веха (длительность 0) — только для событий («В проде, 1%», «Код-фриз»), всегда с подписью.
- Названия ≤ 30 символов.
- Старт — ближайший понедельник от сегодняшней даты (или дата продакта), назови его одной строкой.

## Архитектура — SVG
Образец: `references/architecture-svg-example.svg` (4 яруса: UI → ViewModel → интерфейсы → реализации, легенда внизу). Бери его сетку и координаты, меняй подписи и число блоков нижнего яруса. Классы `c-*`, `t/ts/th`, `arr` есть только в виджете чата — в Artifact SVG-схему не переносить, там рисуй её HTML-блоками или mermaid.
- ≤ 8–10 узлов; больше — разбей на обзор (модули) + деталь (слои внутри фичи).
- Цвета по смыслу: UI/presentation — один ramp, data — второй, платформенное/внешнее — серый. Интерфейсы помечай подписью «interface».
- Пояснения — в тексте ответа, не внутри виджета.

## Если виджета нет
1. Artifact «System Design: <фича>» (Claude Code в терминале): перед публикацией загрузи скилл `artifact-design`. Шаблон Ганта вставляется как есть (fallback-цвета уже внутри). Обновляй один артефакт, давай ссылку.
2. Совсем ничего — mermaid-текстом + «откроется в GitHub / Android Studio / Obsidian».

**Никогда не утверждай, что диаграмма читаемо отрисована, по одному факту отсутствия ошибки** — попроси пользователя глянуть один раз в начале сессии.
